For all of you Evo users out there - you can now have Swype on your phone. If you don't know what Swype is - move along, this post will bore you. Ok - for those of you that are still running the stock Sprint version of the phone - just download the latest Over The Air (OTA) update. Swype is included and you can confirm it's there by simply hitting Menu, Settings, scroll down to Language and keyboard. If you see Swype - its installed. To use it - just touch and hold in a typing field (like when you search or create an email or text). After a second or so, you will see "Input method". When you touch that, there it is - Swype. You are done - enjoy the awesomeness   of Swype. Now for the hard part - you reckless-rooting-master-of-your-own-phone person... If you have root'ed your phone and are running a custom ROM like the amazing CyanogenMod - then you have a few more hoops to jump through. First  - you need to get the OTA version of Swype.apk and the lib file (named libSwypeCore.so). Here is the link (<a href="http://fotadl.htc.com/OTA_supersonic_3.70.651.1-3.30.651.3_releasekobxwrvtv9q86pp0.zip">OTA 3.70.651.1</a>) that worked for me - BUT know this - all links for software usually go broken sooner than later - so if the link doesn't work - google for it and check xda forums. Now you will find a system folder in the OTA zip file - in that folder there is a lib folder. In that folder - there is libSwypeCore.so. Copy that to your phone's sdcard. Also in the system folder, you will see a folder called app. In there you will find the Swype.apk. Copy that to your phone's sdcard. Here comes the hard part. You need to mount the system partition of your phone into read/write mode. I used a QuickSSH to access a shell - but you can use abd shell or whatever. If you are already lost - you shouldn't be running a mod - go back to the sprint software and run the OTA. From the shell, you need to find the mount point for system. <p style="padding-left: 60px;"><em>UPDATE: You don't need the following block quote of info - instead, just installed "Super Manager" from the app store - its free and it allows you to change the file system without all the complicated commands below. Once you have Super Manager installed, open it, click on settings, then Enable ROOT function, then file explorer. You can move to the sdcard, cut the lib file, and when you go to paste it in the /system/lib director - the software will ask you if you want to change it to read/write! Much easier process than the steps below:</em></p> <p style="padding-left: 30px;">I got that information using info from <a href="http://android-tricks.blogspot.com/2009/01/mount-filesystem-read-write.html">here</a>. Before you continue: WAIT! Never cut and paste a command from the internet to your system - figure out what it does FIRST! Here is an example of the commands you need:</p> <p style="padding-left: 30px;">$ <strong>adb shell</strong> $ <strong>su</strong> # <strong>mount -o rw,remount -t yaffs2 /dev/block/mtdblock3 /system</strong></p> <p style="padding-left: 30px;">Remember - you need to get your /dev/block/mtdblockX path from /proc/mounts. I did a cat /proc/mounts | grep system to find that mine was mtdblock4. Once you have that - replace your path with the one in the example above.</p> After you have a read/write file system - you can copy the lib file to /system/lib/. Reboot the phone (this may not be a required step, but its good practice). Open your sdcard and install the Swype.apk. after that - its the same as the OTA - touch and hold on any text input field - wait for "Input method" then select Swype. For me, this worked like a champ! Let me know how it works for you!
