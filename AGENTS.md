# Sackrider.org Family Blog & Archive — Agent Guidelines

This repository contains the source code and Markdown archives for the **Sackrider family blog** at [sackrider.org](https://sackrider.org).

## Key Workflows
* **Write/Edit Content:** `src/content/blog/<slug>.md`
* **Media Assets:** `public/wp-content/uploads/`
* **Local Build:** `npm run build`
* **Local Preview:** `npm run dev`
* **Deploy to Cloudflare:** `npx wrangler deploy`
* **Push to GitHub:** `git push origin main`

## Guidelines
Follow the **`sackrider-org-blog`** skill instructions for voice, tone, family archive formatting, media handling, and publishing checklists.
